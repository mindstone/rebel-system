# Skills

Efficient, composable patterns and best practices for common operations by AI agents.


For creating documents, use [word-docx](utilities/word-docx/SKILL.md), [powerpoint-pptx](utilities/powerpoint-pptx/SKILL.md) and [excel-xlsx](utilities/excel-xlsx/SKILL.md) first. For PDF merge, stamp, text reading and pages as images, use [pdf-edit](utilities/pdf-edit/SKILL.md); for AcroForms, use [pdf-fill-form](utilities/pdf-fill-form/SKILL.md); for a chart as an image, use [chart-image](utilities/chart-image/SKILL.md). To read a saved email (.eml, .msg) or calendar invite (.ics), use [email-calendar-files](utilities/email-calendar-files/SKILL.md). To resize, crop, rotate or convert an image, use [image-edit](utilities/image-edit/SKILL.md). They use built-in libraries and work offline. For SQL over CSV, Parquet or JSON files too large to read whole, use [large-data-duckdb](data-analysis/large-data-duckdb/SKILL.md); its library downloads once on first use. To typeset a polished PDF (a report, letter or paper with maths, tables and images), use [typst-pdf](utilities/typst-pdf/SKILL.md); its library also downloads once on first use. Existing-document redlining and tracked changes use the Anthropic skills.
