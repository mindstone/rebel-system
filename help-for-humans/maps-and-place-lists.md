# Maps and place lists

**Coming soon** — Geographic map views are not in a released version of Rebel yet.

Ask Rebel to put places on a street map so you can compare locations and the information attached to them. For example: “Show these customer sites on a map, with the open issues for each site.”

## Choose what comes first

Rebel chooses a layout when it creates the view. Use **Map first** or **List first** to put the map or the place list first. Changing the layout changes the presentation, not the original records.

Select a pin or a place in the list to inspect its details. Places without a location remain in the list without a pin.

## Move around the map

Drag the map to move it. Use **+** and **−** to zoom in and out. **Fit places** brings all located places back into view.

On a phone, swipe on the controls or content outside the map to scroll the panel. Dragging inside the map moves the map.

## Ask Rebel to act

If Rebel has added an action to a place, select it to ask Rebel to do it. Check Rebel’s response for the result and handle any approval request as usual.

Choose **Save as app** to keep the view as a reusable app inside Rebel. Reopen it from [Library](rebel://library). Ask Rebel to update the view when you need new information.

## If the map cannot load

The full place list remains available while the street background is loading or unavailable. If you’re online, choose **Try the map again**. If you’re offline, reconnect before asking Rebel for new information or using an action.
